# 10 · Code vs Cowork: mismo motor, otro escritorio

Sección del deck: "Code = el trabajo vive en git. Cowork = el deliverable es un
doc, deck o sheet."

## Ejercicio · El mismo análisis, sin terminal (10 min)

Este es para los perfiles no-dev (o para que tú se lo enseñes a alguien no-dev):

1. Abre **Claude Cowork** y crea un workspace con una copia de `06-mcp/vacantes.json`
   (arrástralo como archivo).
2. Pide: "Analiza estas vacantes: rangos de sueldo por ciudad, stacks más pedidos,
   y arma una tabla comparativa lista para presentar."
3. Pide el deliverable: "Conviértelo en un documento de una página para mi jefa."

**Compara con Code:** mismo motor agentic, pero aquí el resultado es un documento,
no un diff. Nadie abrió una terminal.

## El checklist (slide 83)

- ¿El resultado es un diff? → Code
- ¿Es un documento? → Cowork
- ¿Necesitas CI y branches? → Code
- ¿Trabajo de oficina con archivos? → Cowork
- ¿Los dos? → Normal: producto en Code, el resto de la empresa en Cowork
