# claude-code-workshop-gdl-practica

Repo de ejercicios del workshop. Root = mapa; el detalle vive en cada carpeta.

## Estructura
- `03-conceptos/` a `11-insights/`: un ejercicio por sección del deck, cada una con README
- `apps/pagos/`: app de juguete con bugs sembrados (la usan 07, 08 y 09); ver `apps/pagos/CLAUDE.md`
- `guia/index.html`: el mapa visual de los ejercicios

## Reglas del repo
- Los bugs de `apps/pagos/` están sembrados A PROPÓSITO: no los "arregles" salvo que un ejercicio lo pida
- Todo secreto aquí es falso; aún así, `.env` está fuera de alcance por hook
- Los ejercicios se practican en español, términos técnicos en inglés

## Por qué este archivo es corto
Es el ejemplo vivo de la sección 03: cada línea pasó el test
"would removing this cause mistakes?". El resto son pointers.
